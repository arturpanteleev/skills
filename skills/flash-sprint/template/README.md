# Шаблон страницы Flash Sprint

Это зафиксированный вид страницы спринта: один HTML-файл, который владелец читает как документ, а агент обновляет между сессиями. Оформление не меняй без просьбы владельца. Меняются только данные.

## Как собрать

```
python3 ~/.claude/skills/flash-sprint/template/build.py <папка спринта> [--out sprint.html]
```

В папке спринта лежат описания и состояние отдельно:

| Файл | Что в нём |
|---|---|
| `tasks.json` | `sprintId`, `product`, `groups[]` (темы карточек), `batches[]` (пакеты), `globalHuman[]`, `tasks[]` |
| `intro.json` | `number`, `lead`, `story[]`, `focus[]`, `details[]`, необязательно `keywords[]` |
| `sprint_status.json` | `{updatedAt, statuses: {ID: 0..6}}`. Генератор его не меняет |

Рабочий пример данных — в `example/`. Проверь им сборку: `python3 build.py example --out /tmp/example.html`.

Поля задачи: `id`, `group`, `priority` (P0–P3), `type`, `title`, `what`, `body[]`, `jira[]`, `batch`, `human[]`.

## Правила текста

1. **Название страницы:** `Flash Sprint <число>`. Без дат и срока: сколько спринт продлится, неизвестно. Число идёт в `intro.json.number`.
2. **`lead`** — одно простое предложение о цели.
3. **`story`** — короткий рассказ «на чём концентрируемся» человеческим языком. Страница показывает его на всю ширину.
4. **`focus`** — блоки по темам, по два в ряд. Описание каждого блока развёрнутое, 4–7 предложений: что чиним, почему, что с чем связано. Список задач блока открывается под спойлером.
5. **Порядок** строится автоматически по трём ступеням приоритета: максимальный (P0), средний (P1), минимальный (P2 и P3). Не пиши «сегодня, завтра, послезавтра»: сроки неизвестны.
6. **Карточка:** название, `what` и путь статуса. `what` — одно-два предложения простым языком. Всё техническое (где в коде, приёмка, зависимости, файлы) идёт в `body` и показывается под спойлером «Подробности для исполнителя».
7. **Выделение внутри текста.** Текст обычный, не жирный. Выделяются только:
   - ключевые слова жирным: `**планировщик**`, а также термины из `keywords` (по умолчанию планировщик, аналитик, круг добора, база зоны, карта свидетельств, диспетчер, каталог проверок, триаж, лаборатория, карточка агента, схема агента);
   - идентификаторы кодом: пути, `snake_case`, `camelCase`, `ENV_ИМЕНА`, `make цели` — генератор оформляет их сам, остальное оборачивай в обратные кавычки;
   - ссылки: `NX-12` и подобные ведут на карточку, `CD-1234` и `AR-1234` — в Jira, делаются автоматически;
   - курсивом `*так*` — оговорки и неподтверждённое.
8. **Метка в начале абзаца подробностей** («Сейчас:», «Сделать:», «Приёмка:») автоматически становится жирной.
9. **Пакеты.** Задачи, которые правят одни и те же файлы, объединяются в пакет: один пакет — один PR, пакеты не пересекаются по файлам. Пакет виден в подробностях карточки и в разделе «Как делаем».
10. **«Что нужно от людей»** живёт внизу этой же страницы, отдельной страницы нет. Пункты берутся из `globalHuman` и из `human` в задачах, группируются по адресату, у каждого есть галочка (хранится в браузере).
11. Не добавляй в страницу ретро прошлых спринтов, сверки с планами и подписи вроде «снимок на дату». Это отдельные документы.

## Что есть на странице

Прогресс спринта по статусам; блоки тем; приоритеты по ступеням со ссылками на задачи; панель с фильтрами (приоритет, статус, тема), «Развернуть подробности» и экспорт статусов; карточки со статусом-путём (Не взято → В работе → Ревью → Смержено → На проде, плюс «Готово без PR» и «Нужен человек»); раздел «Что нужно от людей»; раздел «Как делаем» с пакетами. Тёмная тема включается по настройке системы.

Статусы хранятся в `localStorage` браузера и в `sprint_status.json`. Перед пересборкой возьми свежий экспорт («Скачать статусы»), если владелец менял их в браузере.

## Оформление (зафиксировано)

Тёплые серые поверхности, акцент — приглушённый синий. Заголовки — Unbounded, текст — Golos Text, код — JetBrains Mono (Google Fonts, у каждого шрифта есть запасной). Приоритет показан цветной полосой слева и меткой: максимальный кирпичный, средний охра, минимальный серый. Текущий статус — капля на линии пути. Карточки скруглены, подробности свёрнуты по умолчанию.
