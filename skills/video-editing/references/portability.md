# Перенос и запуск

Пакет представляет собой обычную папку Agent Skills. Он не требует BB, MCP, API-ключей, SDK конкретной модели или доступа к старому чату. Агент читает SKILL.md, затем вызывает скрипты через терминал. Сам по себе скилл не добавляет агенту отсутствующую возможность просматривать видео/картинки или слушать звук.

## Размещение

Переноси **всю папку video-editing**, включая scripts/, references/, assets/ и agents/. Код не зависит от имени пользователя или абсолютного пути установки.

- Codex: `~/.codex/skills/video-editing/` (также возможна проектная `.agents/skills/video-editing/`).
- Claude Code: `~/.claude/skills/video-editing/` для всех проектов либо `.claude/skills/video-editing/` внутри проекта. Вызов: `/video-editing` или обычная просьба, подходящая описанию скилла.
- OpenCode: `.opencode/skills/video-editing/` либо `.agents/skills/video-editing/`; для глобального использования `~/.config/opencode/skills/video-editing/`. Агент может обнаружить скилл по описанию; доступность зависит от его разрешений и версии.
- Другой harness с Agent Skills: используй документированную папку скиллов. Если автоматического обнаружения нет, явно попроси прочитать SKILL.md по пути и следовать ему.

`agents/openai.yaml` — необязательные метаданные интерфейса Codex; остальной пакет от них не зависит. Пользовательские правила находятся в скилле, поэтому чтение AGENTS.md другого продукта не требуется. Не называй реальный запуск в Claude/OpenCode проверенным до фактического теста в них.

## Зависимости

Python 3.10+, FFmpeg и ffprobe должны быть на PATH. В сборке FFmpeg нужны libx264 и libx265 для соответствующих исходников. Команда doctor показывает наличие инструментов/кодеков; она ничего не устанавливает. Используй сборку FFmpeg для своей ОС. На macOS можно установить `brew install ffmpeg`; на Windows/Linux используй официальный способ для своей системы/дистрибутива. Сначала проверяй наличие, не переустанавливай работающие инструменты.

Рендер/проверки используют стандартную библиотеку Python. Дополнительные пакеты нужны для анализа/контактных листов. Создай venv в проекте или в отдельном каталоге инструментов:

```bash
python3 -m venv .venv-video
.venv-video/bin/python -m pip install -r /path/to/video-editing/scripts/requirements.txt
.venv-video/bin/python /path/to/video-editing/scripts/video.py doctor
```

Windows: используй `.venv-video\Scripts\python.exe` вместо `.venv-video/bin/python`. Не копируй venv между ОС и не клади её в архив скилла. Если включены системные ограничения, выполняй установки в пределах разрешений текущего harness.

## Пример просьбы

«Используй video-editing. Из видео в этой папке собери бодрый Reels около 15 секунд, с понятными сменами движений и взглядами в камеру. Найди разрешённый tropical house трек. Сначала создай сценарий, потом черновик; сохрани исходный HDR, нарезки и компактный MP4. Без AI-кадров и случайных эффектов».
